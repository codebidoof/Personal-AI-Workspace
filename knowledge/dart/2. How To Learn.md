## 1. 실습 환경

### DartPad: 설치 없이 바로 시작

Dart나 Flutter를 설치하지 않았다면 **[dartpad.dev](https://dartpad.dev)** 에서 바로 Dart 코드를 작성하고 실행할 수 있다.

- **에러 표시**: 세미콜론을 빠뜨리면 하단에 `error line 2 • Expected to find ';'.` 처럼 에러가 바로 표시된다.
- **문서 패널**: `print` 같은 식별자에 커서를 두면 Documentation 패널에 시그니처(`void print(Object? object)`)와 설명, 라이브러리 문서 링크가 나타난다.
- **실행**: `Run` 버튼을 누르면 오른쪽 Console에 결과가 출력된다.

```dart
void main() {
  print('hello world');
}
```

### 로컬 환경: Dart / Flutter가 이미 설치된 경우

Flutter를 설치했다면 Dart도 이미 설치되어 있다.

1. 새 프로젝트 폴더를 만든다. (예: `dart_tour`)
2. 그 안에 `main.dart` 파일을 만든다.
3. VS Code를 사용한다면 **Flutter 확장**을 설치하는 것을 추천한다.
4. `main` 함수 위의 `Run`을 누르면 Debug Console에 결과가 출력된다.

강의는 VS Code로 진행하지만, DartPad로 따라가도 결과는 같다. 콘솔 위치와 색만 다를 뿐이다.

## 2. 커리큘럼

강의에서 보여준 코스 목차는 다음과 같다.

- **Dart Overview**: JIT, AOT / How to take this course?
- **Hello World**
- **Variables**: `var`, Null Safety, `late`, `final`, `const`
- **Built-in types**: Numbers, Strings, Booleans, Lists(collection if, collection for), Sets, Maps
- **Functions**: Named Parameters, Optional Positional Parameters
- **Operators**: `??`, Cascade notation
- **Exceptions**
- **Classes**: Instance Variables, Generative Constructors, Named Constructors, Factory Constructors, Methods, Abstract Methods and Classes, Interfaces, Enums, Mixins
- **Typedefs**

### Classes에 시간을 많이 쓰는 이유

Dart는 **진정한 객체 지향 언어**이고, Flutter도 **객체 지향 프레임워크**다.
Flutter에서는 모든 것이 클래스이므로, 클래스의 동작 방식과 Dart 클래스만의 기능을 깊게 다룬다.

### 이 코스의 범위

이 코스는 **Dart 전체를 다루는 투어가 아니다.**
Dart 언어와 API, 그리고 강사가 실제로 Flutter로 만들어 본 것들을 바탕으로, **Flutter를 사용할 때 필요한 Dart 기능만 골라서** 구성했다. 그래서 강의 분량이 길지 않다.

## 정리

- 설치 없이 **DartPad**로 바로 실습할 수 있다. 이미 Flutter가 설치되어 있다면 VS Code + Flutter 확장을 쓰면 된다.
- 코스는 변수 → 내장 타입 → 함수 → 연산자 → 예외 → **클래스** 순서로 진행되며, 클래스 비중이 가장 크다.
- 목표는 Dart 전체가 아니라 **Flutter에 필요한 Dart**다.
