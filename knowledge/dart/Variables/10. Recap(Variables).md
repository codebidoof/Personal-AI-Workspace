Variables 섹션(#1.1 ~ #1.6)에서 배운 내용을 한 번에 복습하는 강의다. 강의 순서대로 정리하고, 자세한 내용은 각 노트로 연결한다.

## 1. 변수 만들기: 타입 명시 또는 `var` → [[4. The Var Keyword]]

```dart
String name = 'nico'; // 타입 명시
var name = 'nico';    // var
```

- 두 방식 모두 **나중에 수정할 수 있다.** 단, 같은 타입으로만 바꿀 수 있다.
- Dart 스타일 가이드는 **가능하면 `var`** 를 권장한다.
  - 함수나 메서드 안의 **지역 변수**: `var` (컴파일러가 타입을 추론한다)
  - **클래스 프로퍼티**: 타입 명시

## 2. `final`: 한 번만 할당 → [[7. Final Variables]]

```dart
final name = 'nico';
name = 'las'; // ❌
```

값을 한 번만 할당하고 다시 바꾸지 못하게 할 때 `var` 대신 `final`을 쓴다.

## 3. `dynamic`: 타입을 모를 때 → [[5. Dynamic Type]]

```dart
dynamic name;
name = 'nico';
name = 12;
name = true;

if (name is String) {
  name.isEmpty; // String임이 확인된 블록 안에서만 String 기능 사용
}
```

- 어떤 타입이든 담을 수 있지만 **조심해서, 가끔만** 써야 한다.
- 사용할 때는 `is`로 타입을 먼저 확인한다.

## 4. `const`: 컴파일 타임 상수 → [[9. Constant Variables]]

```dart
const API_KEY = '121212';
```

- 컴파일할 때(앱스토어에 올리기 전에) **값을 이미 아는** 경우에 쓴다. 수정할 수 없다.

### `const`와 `final`의 차이

|         | 값이 정해지는 시점                  | 예                    |
| ------- | --------------------------- | -------------------- |
| `const` | **컴파일 타임**. 배포 전에 값을 알아야 한다 | API 키                |
| `final` | **런타임**에 정해져도 된다            | 사용자가 폼에 입력한 username |

## 5. Null Safety: nullable 변수 → [[6. Nullable Variables]]

```dart
String name = 'nico';
name = null; // ❌ 기본적으로 non-nullable

String? name = 'nico';
name = null; // ✅ ?를 붙이면 nullable

if (name != null) {
  name.isEmpty; // null 체크 후 사용
}
name?.isEmpty;  // 단축 문법
```

- Dart의 변수는 **기본적으로 null이 될 수 없다.**
- null은 "값이 없음"을 표현하는 유효한 상태다. 피해야 할 것은 null을 **참조**하는 것이다.
- null을 허용하려면 `?`를 붙이고, 사용하기 전에 null 체크를 한다.

## 6. `late`: 나중에 값 넣기 → [[8. Late Variables]]

```dart
late final String name;
// API 호출 등
name = 'nico';
```

- `final`, `var`, 타입 **앞에** 붙이는 수식어다.
- 아직 데이터가 없는 변수를 먼저 선언하고, **값을 넣기 전에는 사용하지 못하게** Dart가 확인해 준다.
- Flutter에서 **API로 데이터를 가져올 때** 자주 쓴다.

## 7. 외우지 말고 이해하기

언제 `var`, `final`, `const`, `late`를 쓰는지는 **실제 앱을 만들면서 연습하다 보면** 자연스럽게 알게 된다. 지금은 외우지 말고 개념만 이해하면 된다.

## 한눈에 보기

| 키워드 | 수정 가능 | 핵심 |
|---|---|---|
| `var` / 타입 명시 | ✅ (같은 타입으로) | 지역 변수는 `var`, 클래스 프로퍼티는 타입 명시 |
| `final` | ❌ | 한 번만 할당. 런타임에 값이 정해져도 된다 |
| `const` | ❌ | 컴파일 타임 상수 |
| `dynamic` | ✅ (아무 타입) | `is`로 타입 확인 후 사용. 가능하면 피한다 |
| `Type?` | ✅ | null 허용. 사용 전 null 체크 |
| `late` | 수식어 | 값 없이 선언하고 나중에 할당 |
