Dart의 `const` 키워드와 **컴파일 타임 상수(compile-time constant)** 를 다루는 강의다.

## 1. Dart의 `const`는 JS/TS의 `const`와 다르다

|                | 의미                                                               |
| -------------- | ---------------------------------------------------------------- |
| JS/TS의 `const` | 재할당할 수 없는 변수. Dart의 **`final`** 과 비슷하다. ([[7. Final Variables]]) |
| Dart의 `const`  | **컴파일 타임 상수**를 만든다.                                              |

## 2. `const`도 수정할 수 없다

```dart
const name = 'nico';
name = '12'; // ❌ 상수는 수정할 수 없다
```

수정할 수 없다는 점에서는 `final`과 똑같이 동작한다.

## 3. 차이점: 값을 컴파일 시점에 알아야 한다

`const` 변수의 값은 **컴파일할 때 이미 알고 있어야** 한다.

```dart
const API_KEY = '121212';     // ✅ 코드에 직접 적은 값. 컴파일 시점에 알 수 있다
const API = fetchApi();       // ❌ 앱이 실행될 때 가져오는 값. 컴파일 시점에 알 수 없다
var API = fetchApi();         // ✅ 이런 값은 var 또는 final로
```

- **API 키**처럼 코드에 직접 붙여 넣어 두고 절대 바뀌지 않는 값은 `const`로 만들 수 있다.
- **API 요청 결과**는 사용자가 폰에서 앱을 실행할 때 정해진다. 컴파일러가 값을 알 수 없으므로 `const`가 될 수 없고, `final`이나 `var`를 쓴다.

### 판단 기준: 앱스토어에 올리기 전에 값을 아는가

| 값을 아는 시점                                    | 사용할 키워드          |
| ------------------------------------------- | ---------------- |
| 앱을 앱스토어에 올리기 **전**에 안다 (예: API 키, 최대 허용 가격) | `const`          |
| 앱 실행 **중**에 정해진다 (API 응답, 사용자 입력)           | `final` 또는 `var` |

```dart
const maxAllowedPrice = 120;
```

## 4. 외우지 말고 이해하기

`final`, `late`, `const`가 헷갈릴 수 있다. 강의에서는 **외우려 하지 말고 개념을 이해하는 데 집중하라**고 강조한다. Flutter를 배우면서 계속 반복해서 보게 된다. 다음 강의는 지금까지 배운 변수 관련 내용의 **전체 복습**이다.

## 정리

- Dart의 `const`는 **컴파일 타임 상수**다. JS/TS의 `const`는 Dart의 `final`에 가깝다.
- `const`도 `final`처럼 수정할 수 없지만, 값을 **컴파일 시점에 알아야** 한다는 점이 다르다.
- 앱 배포 전에 값을 알면 `const`, 실행 중에 정해지면 `final`이나 `var`를 쓴다.
