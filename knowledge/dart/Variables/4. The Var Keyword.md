Dart에서 변수를 만드는 두 가지 방법(`var`, 명시적 타입)과 각각을 언제 쓰는지 다루는 강의다.

## 1. `var` 키워드로 변수 만들기

가장 기본적이고 어디서나 볼 수 있는 방법이다. `var` + 식별자 + 값 순서로 작성한다.

```dart
void main() {
  var name = '니꼬';
}
```

- 타입을 적지 않아도 **컴파일러가 타입을 추론**한다. `name`에 마우스를 올리면 `String`으로 표시된다.

## 2. 변수는 수정할 수 있다. 단, 같은 타입으로만

```dart
var name = '니꼬';
name = 'nico'; // ✅ String → String
name = 1;      // ❌ int는 String에 넣을 수 없다
name = true;   // ❌ bool도 마찬가지
```

`var`로 선언해도 **처음 추론된 타입은 고정**된다. 다른 타입을 넣으려고 하면 Dart가 에러로 막아 준다.

## 3. 타입을 명시해서 변수 만들기

`var` 대신 타입을 직접 적을 수도 있다.

```dart
void main() {
  String name = '니꼬';
  name = 'nico'; // ✅ 명시적 타입이어도 수정 가능
}
```

`var`를 `String`으로 바꿔도 동작은 달라지지 않는다. 두 방식 모두 **같은 타입이면 값을 수정할 수 있다.**

## 4. 언제 무엇을 쓰는가 (컨벤션)

| 상황                   | 권장    |
| -------------------- | ----- |
| 함수나 메서드 안의 **지역 변수** | `var` |
| 클래스의 **프로퍼티**        | 타입 명시 |

강의에서는 Dart 스타일 가이드가 지역 변수에 **가능하면 `var`를 쓰라고 권장**한다고 설명한다. 타입을 적지 않아도 컴파일러가 알고 있기 때문이다.
실제로는 두 방식을 모두 보게 되며, 코스를 진행하면서 상황에 따라 섞어 쓴다.

## 정리

- 변수는 `var` 또는 **명시적 타입**으로 만든다.
- `var`로 만들어도 타입은 추론되어 고정되므로, **같은 타입으로만 수정**할 수 있다.
- 지역 변수에는 `var`, 클래스 프로퍼티에는 명시적 타입을 쓰는 것이 컨벤션이다.
