여러 타입을 가질 수 있는 변수를 만드는 `dynamic` 키워드와, `dynamic` 변수를 안전하게 사용하는 방법을 다루는 강의다.

Dart는 규칙이 엄격한 언어지만, 필요할 때는 그 규칙에서 **조금 벗어날 수 있는 자유**를 준다. 그 수단이 `dynamic`이다.

## 1. `dynamic`: 어떤 타입이든 담을 수 있는 변수

### 값 없이 `var`로 선언하면 `dynamic`이 된다

```dart
void main() {
  var name; // 마우스를 올리면 dynamic으로 표시된다
  name = 'nico';
  name = 12;
  name = true;
}
```

선언할 때 값을 넣지 않으면 컴파일러가 타입을 추론할 수 없으므로 `dynamic`이 된다.
그래서 `String`, `int`, `bool` 무엇이든 넣을 수 있다.

### `dynamic`을 직접 명시할 수도 있다

```dart
dynamic name;
name = 'nico';
name = 12;
name = true;
```

[[4. The Var Keyword]]에서 `var` 대신 타입을 명시했던 것과 같은 관계다.

## 2. `dynamic` 변수를 사용할 때는 타입을 먼저 확인한다

`dynamic` 변수에 `name.`을 입력해도 자동완성에 메서드가 거의 나오지 않는다. **Dart가 이 변수의 타입을 모르기 때문**이다.

`is`로 타입을 확인하면, 그 `if` 블록 안에서는 Dart가 해당 타입으로 인식한다.

```dart
dynamic name;

if (name is String) {
  name.isEmpty;    // String의 프로퍼티와 메서드 사용 가능
  name.length;
}

if (name is int) {
  name.isEven;     // int의 프로퍼티 사용 가능
  name.isOdd;
  name.isInfinite;
}
```

- `if (name is String)` 블록 안: `isEmpty`, `isNotEmpty`, `length`, `contains` 등이 자동완성에 나온다.
- `if (name is int)` 블록 안: `isEven`, `isOdd`, `isFinite`, `isInfinite`, `sign` 등이 나온다.
- 블록 **바깥**에서 `name`은 여전히 `dynamic`이다.

> [!note] 보충
> 강의에서 용어를 언급하지는 않지만, 이렇게 `is` 검사 뒤에 변수가 더 구체적인 타입으로 취급되는 것을 Dart에서는 **type promotion**이라고 부른다.

강의에서는 이 과정에서 Dart의 기본 타입이 `isEven`, `isOdd`, `isEmpty`처럼 **편리한 프로퍼티를 많이 제공한다**는 점도 함께 보여 준다.

## 3. 언제 `dynamic`을 쓰는가

- **권장하지 않는다.** 가능하면 피하고, **정말 필요할 때만** 쓴다.
- 하지만 유용하거나, 유일한 선택지일 때가 있다.
  - 인터넷에서 가져온 데이터처럼 **형태를 미리 알 수 없는 경우**. Flutter에서 **JSON**을 다룰 때 자주 보게 된다.
  - 이때 `dynamic`으로 받은 뒤 `is`로 타입을 확인해서 사용한다.

## 정리

- `dynamic`은 **어떤 타입이든 담을 수 있는** 변수 타입이다. 값 없이 `var`로 선언해도 `dynamic`이 된다.
- `dynamic` 변수는 `is`로 **타입을 확인한 블록 안에서만** 해당 타입의 기능을 쓸 수 있다.
- JSON처럼 타입을 알 수 없는 데이터에 쓰되, 가능하면 피한다.
