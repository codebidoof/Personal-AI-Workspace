named parameters를 쓰지 않으면서도 **positional parameter 일부를 생략할 수 있게** 만드는 방법을 다루는 강의다.

## 1. 복습: positional parameters는 모두 필수다

```dart
String sayHello(String name, int age, String country) =>
    'Hello $name, you are $age years old from $country';

sayHello('nico', 12, 'cuba'); // 세 개를 순서대로 모두 보내야 한다
```

지금까지 배운 positional parameters는 **모두 필수**이고, 순서도 지켜야 한다. ([[19. Recap (Parameters)]])

## 2. optional positional parameters: `[]`로 감싼다

`country`만 선택 사항으로 만들고 싶다면, 그 파라미터를 **대괄호 `[]`** 로 감싸고 **기본값**을 준다.

```dart
String sayHello(String name, int age, [String? country = 'cuba']) =>
    'Hello $name, you are $age years old from $country';

void main() {
  var results = sayHello('nico', 12); // 마지막 인자를 생략할 수 있다
  print(results); // Hello nico, you are 12 years old from cuba
}
```

- `[]` 안의 파라미터는 **생략할 수 있다.**
- 강의에서는 타입에 `?`를 붙여 nullable로 만들고 기본값을 주는 방식으로 작성한다.
- 인자를 보내지 않으면 기본값 `'cuba'`가 쓰인다.

> [!note] 보충
> 기본값이 있으면 값이 null이 될 일이 없으므로 `?` 없이 `[String country = 'cuba']`로 써도 된다. 반대로 기본값 없이 `[String? country]`로 쓰면, 생략했을 때 `country`는 `null`이 된다.

## 3. 파라미터 종류 비교

| 종류 | 문법 | 호출 |
|---|---|---|
| positional (필수) | `(String name)` | `f('nico')` |
| optional positional | `([String country = 'cuba'])` | `f()` 또는 `f('korea')` |
| named | `({required String name})` | `f(name: 'nico')` |

## 4. 강사의 코멘트

- 강사는 이 문법을 **거의 쓰지 않는다**(10번도 안 써 봤다고 한다).
- 문법이 조금 어색해서, 보통은 [[18. Named Parameters|named parameters]]를 더 선호한다.
- 그래도 알아 두라는 의미로 소개한다.

## 정리

- positional parameter를 **`[]`로 감싸고 기본값을 주면** 생략할 수 있다.
- 생략하면 기본값이 쓰인다.
- 실무에서는 named parameters를 더 많이 쓴다.
