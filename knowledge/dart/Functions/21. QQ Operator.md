null을 다룰 때 아주 편리한 **`??` 연산자**와 **`??=` 연산자**를 다루는 강의다. Flutter에서 자주 쓰게 된다.

Dart에도 `&&`, `||`, `>`, `<`, `==`, `!=` 같은 일반적인 연산자는 모두 있다. 강의에서는 그중 특별한 두 가지만 다룬다.

## 1. 문제: nullable 파라미터 다루기

이름을 대문자로 바꿔 반환하는 함수에서, `null`도 받을 수 있게 하고 싶다.

```dart
String capitalizeName(String? name) => name.toUpperCase(); // ❌ name이 null일 수 있다

capitalizeName('nico');
capitalizeName(null);
```

`String?`로 바꾸면 `name`이 null일 수 있으므로, 바로 `toUpperCase()`를 호출할 수 없다. ([[6. Nullable Variables]])

## 2. 점점 짧게 고쳐 보기

### ① `if`로 null 체크

```dart
String capitalizeName(String? name) {
  if (name != null) {
    return name.toUpperCase();
  }
  return 'ANON';
}
```

### ② fat arrow + 삼항 연산자

```dart
String capitalizeName(String? name) =>
    name != null ? name.toUpperCase() : 'ANON';
```

### ③ `??` 연산자

```dart
String capitalizeName(String? name) => name?.toUpperCase() ?? 'ANON';
```

- `?.`: `name`이 null이면 `toUpperCase()`를 호출하지 않고 null을 반환한다.
- `??`: 왼쪽이 null이면 오른쪽 값 `'ANON'`을 쓴다.

## 3. `??` 연산자 (QQ)

```dart
left ?? right
```

| 왼쪽 값          | 결과    |
| ------------- | ----- |
| null이 **아니면** | 왼쪽 값  |
| **null이면**    | 오른쪽 값 |

## 4. `??=` 연산자 (QQ equals)

변수가 **null일 때만** 값을 할당한다.

```dart
void main() {
  String? name;
  name ??= 'nico';     // name이 null이므로 'nico' 할당
  name = null;
  name ??= 'another';  // name이 null이므로 'another' 할당
  print(name);         // another
}
```

- `name ??= 'nico';` 바로 뒤에 또 `name ??= ...`를 쓰면, 이미 값이 있어서 절대 실행되지 않는다. 그래서 에디터가 경고를 보여 준다.
- 중간에 `name = null;`을 넣으면 두 번째 `??=`가 실행된다.

## 정리

- `a ?? b`: `a`가 null이면 `b`, 아니면 `a`를 쓴다.
- `a ??= b`: `a`가 null일 때만 `b`를 할당한다.
- `?.`와 `??`를 함께 쓰면 null 체크를 한 줄로 끝낼 수 있다.
