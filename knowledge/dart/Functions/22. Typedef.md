타입에 **별칭(alias)** 을 붙이는 `typedef`를 다루는 강의다. 타입이 길거나 헷갈릴 때 유용하다.

## 1. 예제: List를 뒤집는 함수

```dart
List<int> reverseListOfNumbers(List<int> list) {
  var reversed = list.reversed;
  return reversed.toList();
}

void main() {
  print(reverseListOfNumbers([1, 2, 3])); // [3, 2, 1]
}
```

`list.reversed`는 List가 아니라 **`Iterable`** 을 반환한다. 그래서 `toList()`로 다시 List로 바꿔서 반환한다.

## 2. `typedef`로 별칭 만들기

`List<int>`가 반환 타입과 파라미터에 반복해서 나온다. 여기에 이름을 붙일 수 있다.

```dart
typedef ListOfInts = List<int>;

ListOfInts reverseListOfNumbers(ListOfInts list) {
  var reversed = list.reversed;
  return reversed.toList();
}
```

- 이름은 원하는 대로 지으면 된다.
- 내부적으로는 **여전히 같은 `List<int>` 타입**이다. 이름만 달라진다.
- 예제는 작지만, 코드가 많고 파일이 클 때 유용하다.

## 3. 구조화된 데이터에는 `typedef` 대신 클래스

Map의 형태를 정하고 싶어서 `typedef`를 쓰고 싶어질 수 있다.

```dart
typedef UserInfo = Map<String, String>;

String sayHi(UserInfo userInfo) {
  return "Hi ${userInfo['name']}";
}

void main() {
  sayHi({"name": 'nico'});
}
```

- 이 코드는 동작한다.
- 하지만 `name` key가 없는 Map을 보내도 여전히 `Map<String, String>`이라 **막을 수 없다.**
- 이렇게 **데이터의 형태(shape)** 를 정하고 싶다면 `typedef`가 아니라 **클래스**를 써야 한다. ([[15. Maps]]에서도 같은 이유로 클래스를 권장했다.)

### `typedef`를 쓰는 곳

`List<int>`, Map, Set처럼 **작은 타입**에 별칭을 붙일 때 쓴다.

## 정리

- `typedef 별칭 = 타입;`으로 타입에 별칭을 붙인다. 실제 타입은 그대로다.
- `List<int>`처럼 작은 타입을 읽기 쉽게 만들 때 쓴다.
- 데이터의 형태를 강제하고 싶다면 클래스를 쓴다.
