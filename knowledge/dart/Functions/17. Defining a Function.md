Functions 섹션의 첫 강의로, 함수를 정의하는 기본 방법과 **반환 타입**, **fat arrow 문법(`=>`)** 을 다루는 강의다.

## 1. 함수 정의하기

```dart
void sayHello(String name) {
  print("Hello $name nice to meet you!");
}
```

- **반환 타입** → 함수 이름 → `(파라미터 타입 파라미터 이름)` 순서로 쓴다.
- 파라미터는 **타입을 명시**해야 한다.
- 문자열 안에서는 [[13. String Interpolation]]으로 파라미터 값을 넣을 수 있다.

## 2. 반환 타입

### `void`: 아무것도 반환하지 않는다

위 `sayHello`는 콘솔에 출력만 하고(side effect) 아무것도 **반환하지 않으므로** 반환 타입이 `void`다.

### 값을 반환하면 반환 타입도 바꿔야 한다

```dart
void sayHello(String name) {
  return "Hello $name nice to meet you!"; // ❌ void 함수가 String을 반환하려 한다
}

String sayHello(String name) {
  return "Hello $name nice to meet you!"; // ✅
}
```

- `String sayHello(String name)`는 **String을 반환**하고 **String 파라미터 하나**를 받는 함수다.
- 파라미터 이름은 무엇이든 상관없다. (강의에서는 `potato`로 바꿔 보여 준다.)

## 3. 함수는 `main` 바깥에 정의하고, `main` 안에서 호출한다

```dart
String sayHello(String potato) {
  return "Hello $potato nice to meet you!";
}

void main() {
  print(sayHello('nico')); // Hello nico nice to meet you!
}
```

- 함수를 `main` 안에 정의할 필요는 없다.
- `main`은 Dart가 호출하는 진입점이고 아무것도 반환하지 않으므로 `void main()`이다. ([[3. Hello World]])

## 4. fat arrow 문법 `=>`

함수가 **바로 값을 반환**하기만 한다면, `{ return ...; }` 대신 `=>`를 쓸 수 있다.

```dart
String sayHello(String potato) => "Hello $potato nice to meet you!";

num plus(num a, num b) => a + b;
```

- `=> 식`은 `{ return 식; }`과 **같다.**
- 코드가 한 줄뿐인 함수에 쓴다.
- API 호출이나 계산처럼 여러 줄이 필요한 함수는 중괄호 `{}`를 쓰고 마지막에 `return`한다.

## 정리

- 함수는 `반환타입 이름(타입 파라미터) { ... }`로 정의한다.
- 아무것도 반환하지 않으면 `void`, 값을 반환하면 그 값의 타입을 반환 타입으로 적는다.
- 바로 반환하는 한 줄짜리 함수는 `=>`로 짧게 쓸 수 있다.
