**모든 요소가 고유한(unique)** 컬렉션인 Set을 다루는 강의다.

## 1. Set 만들기

중괄호 `{}` 안에 값만 나열하면 Set이 된다. (`key: value`를 쓰면 [[15. Maps|Map]]이 된다.)

```dart
var numbers = {1, 2, 3, 4};        // 추론된 타입: Set<int>
Set<int> numbers = {1, 2, 3, 4};   // 타입을 명시해도 같다
```

## 2. Set과 List의 차이: 요소가 고유하다

Set은 **모든 요소가 고유하다는 것을 언어가 보장**한다. 같은 값을 여러 번 추가해도 한 번만 들어간다.

```dart
var numbers = {1, 2, 3, 4};
numbers.add(1);
numbers.add(1);
numbers.add(1);
print(numbers); // {1, 2, 3, 4}
```

같은 코드를 [[12. Lists|List]]로 바꾸면 중복이 그대로 들어간다.

```dart
var numbers = [1, 2, 3, 4];
numbers.add(1);
numbers.add(1);
numbers.add(1);
print(numbers); // [1, 2, 3, 4, 1, 1, 1]
```

| | 괄호 | 중복 |
|---|---|---|
| List | `[]` | 허용 |
| Set | `{}` | 허용하지 않음 |

## 3. 언제 쓰는가

- 요소가 **항상 고유해야 하면** Set을 쓴다.
- 고유성이 상관없으면 List를 쓴다.

강의에서는 다른 언어와 비교해 Dart의 List는 Python의 list와 비슷하고, JavaScript에도 Set이 있다고 설명한다.

> [!note] 보충
> 강의에서 Set이 Python의 tuple과 비슷하다고 말하지만, 정확하지 않다. tuple은 중복을 허용하는 **변경 불가능한 시퀀스**다. Dart의 Set에 해당하는 것은 Python의 **`set`** 이다.

## 정리

- Set은 `{1, 2, 3}`처럼 만들고, 타입은 `Set<int>`처럼 표시된다.
- Set은 **중복을 허용하지 않는다.** 같은 값을 여러 번 `add`해도 한 번만 들어간다.
- 고유성이 필요하면 Set, 필요 없으면 List를 쓴다.
