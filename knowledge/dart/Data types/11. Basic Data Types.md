Data Types 섹션의 첫 강의로, Dart의 **가장 기본적인 데이터 타입**을 다룬다.

## 1. 기본 타입 4가지

```dart
void main() {
  String name = "nico";  // 작은따옴표('nico'), 큰따옴표("nico") 모두 가능
  bool alive = true;     // true 또는 false
  int age = 12;          // 정수
  double money = 69.99;  // 소수
}
```

| 타입       | 설명                       |
| -------- | ------------------------ |
| `String` | 문자열. `'`와 `"` 둘 다 쓸 수 있다 |
| `bool`   | `true` / `false`         |
| `int`    | 정수                       |
| `double` | 소수점이 있는 수                |

## 2. Dart에서는 거의 모든 것이 객체다

이 타입들은 모두 **클래스**다. VS Code에서 타입에 우클릭하고 **Go to Type Definition**을 누르면 확인할 수 있다.

- `String`, `bool`은 클래스다.
- `int`와 `double`은 **`num`** 클래스를 상속한다.
  ```dart
  abstract class int extends num { ... }
  ```

강의에서는 **함수까지도 객체**이기 때문에 Dart를 "진정한 객체 지향 언어"라고 부른다고 설명한다. ([[2. How To Learn]]에서 클래스에 시간을 많이 쓰는 이유와 연결된다.)

### `num`: `int`와 `double`의 부모 클래스

```dart
num x = 12;
x = 1.1; // ✅ int도 double도 담을 수 있다
```

값이 정수일 수도, 소수일 수도 있을 때 `num`을 쓴다. 자주 쓰지는 않지만 `int`와 `double`의 부모라는 점은 알아 둔다.

## 3. 객체이기 때문에 메서드와 프로퍼티가 많다

모든 타입이 클래스에서 나오므로, 변수 뒤에 `.`을 찍으면 자동완성으로 쓸 수 있는 기능을 볼 수 있다.

- `String`: 문자열 관련 메서드가 많다.
- `int` / `double`: `isOdd`, `isEven`, `isNegative` 같은 프로퍼티가 있다. 별도로 **import하지 않아도** 여러 수학 연산을 할 수 있다.

([[5. Dynamic Type]]에서 `is` 체크 후 자동완성으로 봤던 기능들이 바로 이것이다.)

## 정리

- 기본 타입: `String`, `bool`, `int`, `double`
- Dart에서는 거의 모든 것이 **객체**(클래스)다. 함수도 객체다.
- `int`와 `double`은 `num`을 상속한다.
- 객체이기 때문에 각 타입이 유용한 메서드와 프로퍼티를 기본으로 제공한다.
