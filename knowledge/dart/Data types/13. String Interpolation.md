문자열 안에 **변수 값이나 연산 결과를 넣는** String Interpolation을 다루는 강의다. Flutter에서 곧바로 자주 쓰게 된다.

## 1. 변수 값 넣기: `$변수명`

```dart
void main() {
  var name = 'nico';
  var greeting = 'Hello everyone, my name is $name, nice to meet you!';
  print(greeting); // Hello everyone, my name is nico, nice to meet you!
}
```

문자열 안에서 `$` 뒤에 변수 이름을 쓰면 그 값으로 바뀐다.

## 2. 연산 결과 넣기: `${식}`

```dart
void main() {
  var name = 'nico';
  var age = 10;
  var greeting = "Hello everyone, my name is $name and I'm ${age + 2}";
  print(greeting); // Hello everyone, my name is nico and I'm 12
}
```

`${ }` 안에 연산을 쓰면 Dart가 연산을 실행하고, 그 **결과**를 문자열에 넣는다.

| 넣고 싶은 것 | 문법           |
| ------- | ------------ |
| 변수 값    | `$name`      |
| 연산 결과   | `${age + 2}` |

## 3. 작은따옴표와 큰따옴표

- 작은따옴표(`'`)와 큰따옴표(`"`) 중 **아무거나** 써도 된다. Interpolation은 둘 다 똑같이 동작한다.
- 작은따옴표 문자열 안에 `'`(예: `I'm`)가 들어가면 문자열이 끝나 버리므로, `\`로 **이스케이프**해야 한다.

```dart
var greeting = 'Hello everyone, my name is $name and I\'m ${age + 2}';
```

## 정리

- 변수 값을 넣을 때는 `$변수명`을 쓴다.
- 연산 결과를 넣을 때는 `${연산}`을 쓴다.
- `'`와 `"` 모두 쓸 수 있다. 작은따옴표 안의 `'`는 `\'`로 이스케이프한다.
