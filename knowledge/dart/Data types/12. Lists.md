Flutter에서 아주 자주 쓰는 **List**를 만드는 방법, List가 제공하는 기능, 그리고 Dart만의 문법인 **collection if**를 다루는 강의다.

## 1. List 만들기

대괄호 `[]` 안에 값을 나열하면 된다.

```dart
var numbers = [1, 2, 3, 4];        // 마우스를 올리면 List<int>로 추론된다
List<int> numbers = [1, 2, 3, 4];  // 타입을 명시해도 같다
```

- [[4. The Var Keyword]]에서 배운 것처럼 `var`와 명시적 타입 둘 다 쓸 수 있다. 지역 변수는 `var`가 권장된다.
- `List<int>`에는 **정수만** 넣을 수 있다. 문자열을 넣으려고 하면 에러가 난다.

## 2. List의 프로퍼티와 메서드

`List`도 클래스이므로([[11. Basic Data Types]]), `numbers.`을 입력하면 쓸 수 있는 기능이 많이 나온다.

| 기능           | 설명                                |
| ------------ | --------------------------------- |
| `first`      | 첫 번째 요소                           |
| `last`       | 마지막 요소. 요소가 몇 개인지 몰라도 바로 가져올 수 있다 |
| `isEmpty`    | 비어 있는지 확인                         |
| `add()`      | 요소 하나 추가                          |
| `addAll()`   | 여러 요소를 한꺼번에 추가                    |
| `clear()`    | 모든 요소 삭제                          |
| `contains()` | 특정 요소가 있는지 확인                     |

전부 외울 필요는 없고, **이런 기능이 있고 어디서 찾는지**만 알면 된다.

## 3. 팁: 마지막 요소 뒤에 쉼표를 붙인다

VS Code든 DartPad든 List의 마지막 요소 뒤에 **쉼표(trailing comma)** 를 붙이면, 포매터가 자동으로 **여러 줄로 정리**해 준다. List가 복잡해질수록 읽기 쉬워진다.

```dart
var numbers = [
  1,
  2,
  3,
  4,
];
```

## 4. collection if

List를 만들 때 **조건에 따라 요소를 넣을지 말지** 정할 수 있다. 이런 문법을 가진 언어는 많지 않다.

```dart
void main() {
  var giveMeFive = true;
  var numbers = [
    1,
    2,
    3,
    4,
    if (giveMeFive) 5, // giveMeFive가 true일 때만 5가 들어간다
  ];
  print(numbers); // [1, 2, 3, 4, 5]
}
```

위 코드는 아래 코드와 같다. collection if가 이를 짧게 쓰는 방법이다.

```dart
var numbers = [1, 2, 3, 4];
if (giveMeFive) {
  numbers.add(5);
}
```

## 정리

- List는 `[1, 2, 3]`처럼 만들고, 타입은 `List<int>`처럼 요소 타입과 함께 표시된다.
- `first`, `last`, `add`, `contains` 등 기능이 많다.
- 마지막 요소 뒤에 **쉼표**를 붙이면 여러 줄로 보기 좋게 포맷된다.
- **collection if**: `if (조건) 값`으로 조건부 요소를 List 안에서 바로 넣을 수 있다.
