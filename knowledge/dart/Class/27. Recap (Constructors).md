생성자를 복습하는 강의다. Flutter에서 실제로 자주 만나는 상황, 즉 **API에서 받은 JSON 데이터를 클래스로 바꾸는** 예제를 **`fromJson` named constructor**로 구현한다.

Flutter는 모든 것이 클래스이고, 클래스마다 생성자가 있으며, 직접 클래스와 생성자를 만들게 된다. 그래서 일반 생성자와 [[26. Named Constructors|named constructor]]의 차이와 문법을 꼭 이해해야 한다.

## 1. API 데이터 흉내 내기

API에서 JSON 같은 형태로 여러 Player 데이터를 받았다고 가정한다.

```dart
var apiData = [
  {
    "name": "nico",
    "team": "red",
    "xp": 0,
  },
  {
    "name": "lynn",
    "team": "red",
    "xp": 0,
  },
  {
    "name": "dal",
    "team": "red",
    "xp": 0,
  },
];
```

이 **구조화되지 않은 Map**들을 모두 `Player` 클래스로 바꾸고 싶다.

## 2. `fromJson` named constructor

많은 Flutter 앱에서 쓰는 패턴이다.

```dart
class Player {
  final String name;
  int xp;
  String team;

  Player.fromJson(Map<String, dynamic> playerJson)
      : name = playerJson['name'],
        xp = playerJson['xp'],
        team = playerJson['team'];

  void sayHello() {
    print("Hi my name is $name");
  }
}
```

- 파라미터는 `Map<String, dynamic>`이다. key는 String이고 value는 어떤 타입이든 될 수 있는, JSON과 비슷한 형태다. ([[5. Dynamic Type]], [[15. Maps]])
- 콜론(`:`) 뒤에서 **JSON의 각 key 값을 프로퍼티에 하나씩 초기화**한다.
  - 클래스의 `name` ← `playerJson['name']`
  - 클래스의 `xp` ← `playerJson['xp']`
  - 클래스의 `team` ← `playerJson['team']`
- 결국 **Player 클래스를 초기화하는 것**이고, 생성자의 이름만 `fromJson`으로 다를 뿐이다.

> [!note] 보충
> 이번 강의 코드는 initializer list에서 `this.` 없이 `name = ...`으로 쓴다. [[26. Named Constructors]]에서는 `this.name = name`처럼 썼는데, initializer list에서는 두 방식 모두 가능하다.

## 3. 사용하기

```dart
void main() {
  apiData.forEach((playerJson) {
    var player = Player.fromJson(playerJson);
    player.sayHello();
  });
}
// Hi my name is nico
// Hi my name is lynn
// Hi my name is dal
```

`forEach`로 각 Map을 돌면서 `Player.fromJson`으로 Player를 만든다.

## 4. 강사의 당부

- 문법은 외우기 어려우니 **외우지 않아도 된다.**
- 하지만 **어떻게 동작하는지는 이해해야 한다.** `fromJson`을 직접 작성할 때도 있고, named constructor는 아주 많이 쓰게 된다.

## 정리

- API의 JSON 데이터(`Map<String, dynamic>`)를 클래스로 바꿀 때 **`fromJson` named constructor** 패턴을 쓴다.
- `클래스명.fromJson(Map<String, dynamic> json) : 프로퍼티 = json['key'], ...;` 형태다.
- 여러 데이터는 `forEach` 등으로 돌면서 각각 `fromJson`으로 인스턴스를 만든다.
