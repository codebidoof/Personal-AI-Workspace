선택지를 제한해서 **실수를 막아 주는** `enum`을 다루는 강의다. Flutter에서 아주 많이 쓴다.

## 1. 문제: 문자열 값은 오타를 막을 수 없다

```dart
team: 'red'   // ✅
team: 'rred'  // 오타지만 String이라 에러가 나지 않는다
```

- team을 String으로 두면 `'red'` 대신 `'rred'`, `'blue'` 대신 `'bleu'`처럼 **오타를 내도 막을 수 없다.**
- Flutter에는 색상, margin, padding, style, alignment처럼 선택지가 아주 많다. 빨리 읽으면 눈치채기 어려운 오타를 내기 쉽다.
- 개발자가 실수하지 않기를 바라는 대신, **enum으로 선택지 자체를 제한**한다.

## 2. enum 만들기

```dart
enum Team { red, blue }
```

- `enum 이름 { 값1, 값2 }`로 선언한다.
- 값을 **문자열로 쓰지 않는다.** (`'red'`가 아니라 `red`)
- 사실상 **새로운 타입**을 만드는 것이다.

## 3. enum을 타입으로 쓰기

```dart
enum Team { red, blue }

class Player {
  String name;
  int xp;
  Team team; // String이 아니라 Team

  Player({
    required this.name,
    required this.xp,
    required this.team,
  });
}

void main() {
  var nico = Player(name: 'nico', xp: 1200, team: Team.red);
  var potato = nico
    ..name = 'las'
    ..xp = 1200000
    ..team = Team.blue;
}
```

- `team`에는 이제 **`Team.red` 또는 `Team.blue`만** 넣을 수 있다.
- `Team.`을 입력하면 자동완성에 두 선택지만 나온다. 오타를 낼 여지가 없다.

## 4. 원하는 값으로 무엇이든 만들 수 있다

```dart
enum XPLevel { beginner, medium, pro }

class Player {
  String name;
  XPLevel xp; // int 대신 XPLevel
  Team team;
  // ...
}

var nico = Player(name: 'nico', xp: XPLevel.medium, team: Team.red);
```

`int`였던 xp를 `XPLevel`로 바꾸면 코드가 더 읽기 쉬워진다.

## 5. Flutter에서는

- enum을 직접 많이 **만들기**보다는, Flutter가 제공하는 enum을 많이 **쓰게** 된다.
- Flutter 코드는 **enum과 클래스로 가득하다.**

> [!warning] 강의 내용 정정
> 강의에서는 Flutter의 색상(`Colors.red` 등)이 enum일 것이라고 말하지만(강사도 "I think"라고 확신하지 않음), 실제로 `Colors`는 enum이 아니다. `Colors`는 `Color` 타입의 **static const 값들을 모아 둔 클래스**다. 다만 "문자열 대신 미리 정의된 값을 골라 써서 실수를 막는다"는 취지는 같다. Flutter에서 실제 enum의 예로는 `MainAxisAlignment`, `TextAlign`, `BoxFit`, `Axis` 등이 있다.

## 정리

- `enum 이름 { 값1, 값2 }`로 선택지가 정해진 새 타입을 만든다.
- enum 타입의 변수에는 **정해진 값(`Team.red` 등)만** 넣을 수 있어 오타 같은 실수를 막는다.
- Flutter에서는 enum을 아주 많이 쓴다.
