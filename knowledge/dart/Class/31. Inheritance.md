**상속(inheritance)** 과 **`super`**, **`@override`** 를 다루는 강의다. 부모 클래스의 생성자를 호출하는 방법이 핵심이다.

## 1. 부모 클래스 만들기

```dart
class Human {
  final String name;

  Human(this.name);

  void sayHello() {
    print("Hi my name is $name");
  }
}
```

## 2. `extends`로 상속하기

Player도 사람이므로 이름이 있고 인사할 줄 안다. `Human`의 코드를 **복사하지 않고 그대로 가져온다.**

```dart
enum Team { blue, red }

class Player extends Human {
  final Team team;
  // 생성자는 아래에서
}
```

`extends`하면 부모의 **프로퍼티(`name`)와 메서드(`sayHello`)** 를 가져온다.

## 3. 부모 생성자 호출하기: `super`

`Human`의 `name`은 **`Human`의 생성자**가 채운다. 그래서 Player를 만들 때 **부모 생성자도 호출해서 name을 넘겨야** 한다.

```dart
class Player extends Human {
  final Team team;

  Player({
    required this.team,
    required String name,
  }) : super(name);
}

void main() {
  var player = Player(team: Team.red, name: 'nico');
  player.name;       // Human에서 가져온 프로퍼티
  player.team;       // Player의 프로퍼티
  player.sayHello(); // Human에서 가져온 메서드
}
```

- Player 생성자에서 `name`을 받는다.
- 콜론(`:`) 뒤에서 **`super(name)`** 으로 부모 생성자에 넘긴다. ([[26. Named Constructors]]의 콜론 문법과 같다)
- **`super`는 상속한 부모 클래스(superclass)를 가리킨다.**
- `this.name`처럼 받을 수는 없다. `name`은 Human의 프로퍼티이기 때문이다.

### 부모 생성자가 named parameter라면

```dart
class Human {
  final String name;
  Human({required this.name});
  // ...
}

class Player extends Human {
  final Team team;

  Player({
    required this.team,
    required String name,
  }) : super(name: name);
}
```

부모 생성자의 형태에 맞춰 `super(name: name)`으로 넘긴다. named와 positional 중 어느 쪽을 쓸지는 선택이다.

## 4. `@override`: 부모 메서드 다시 정의하기

부모의 `sayHello`를 그대로 쓰지 않고, **내용을 추가해서 바꾸고 싶다.**

```dart
class Player extends Human {
  final Team team;

  Player({
    required this.team,
    required String name,
  }) : super(name);

  @override
  void sayHello() {
    super.sayHello();               // 부모의 sayHello 먼저 실행
    print('and I play for $team');  // 내 코드 추가
  }
}
```

- **`@override`**: 부모에게서 가져온 메서드를 **내 것으로 대체**한다.
- **`super.sayHello()`**: 부모 코드를 복사하지 않고 **부모의 메서드를 그대로 호출**한다.
  - `Human.sayHello()`가 아니라 `super.sayHello()`다.
- `super.`을 입력하면 자동완성에 부모의 `name`, `sayHello()` 등이 나온다.

## 5. 기억할 것

- 상속한 부모 클래스에 **생성자가 있다면, 반드시 부모 생성자를 호출**해서 필요한 값을 넘겨야 한다.
- Python, Java, C#, TypeScript도 부모 생성자(`super`)를 호출하는 점은 같다. Dart는 이를 **콜론 + `super(...)`** 문법으로 쓴다.
- 상속은 자주 쓰게 된다.

## 정리

- `class 자식 extends 부모`로 부모의 프로퍼티와 메서드를 가져온다.
- 생성자에서 `: super(...)`로 **부모 생성자를 호출**해 값을 넘긴다.
- `@override`로 부모 메서드를 재정의하고, 그 안에서 `super.메서드()`로 부모의 원래 동작을 호출할 수 있다.
