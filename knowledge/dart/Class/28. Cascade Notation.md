같은 객체에 여러 작업을 연속으로 할 때 코드를 줄여 주는 **cascade 연산자 `..`** 를 다루는 강의다. [[3. Hello World]]에서 "세미콜론을 자동으로 붙여 주지 않는 이유"로 예고했던 문법이다.

## 1. 준비: 기본 생성자로 돌아가기

```dart
class Player {
  String name;
  int xp;
  String team;

  Player({
    required this.name,
    required this.xp,
    required this.team,
  });

  void sayHello() {
    print("Hi my name is $name");
  }
}
```

name을 수정할 수 있도록 `final`은 뺐다.

## 2. 문제: 같은 변수 이름을 반복한다

```dart
var nico = Player(name: 'nico', xp: 1200, team: 'red');
nico.name = 'las';
nico.xp = 1200000;
nico.team = 'blue';
```

`nico.`을 계속 반복해야 한다.

## 3. cascade 연산자 `..`

```dart
var nico = Player(name: 'nico', xp: 1200, team: 'red')
  ..name = 'las'
  ..xp = 1200000
  ..team = 'blue';
```

- 생성자 호출 뒤의 **세미콜론을 지우고**, 각 줄의 `nico.`을 **`..`** 으로 바꾼다.
- 세미콜론은 **맨 마지막에 한 번만** 붙인다.
- 각 `..`은 **바로 앞의 객체(`nico`)** 를 가리킨다. 위 2의 코드와 **완전히 같은 동작**이다.

> 중간에 세미콜론이 있으면 문장이 끝나 버려 `..`이 이어지지 않는다. 그래서 Dart 포매터는 세미콜론을 자동으로 붙여 주지 않는다. ([[3. Hello World]])

## 4. 이미 있는 객체에도 쓸 수 있다

인스턴스를 만드는 순간이 아니어도 된다.

```dart
var nico = Player(name: 'nico', xp: 1200, team: 'red');
var potato = nico // 참조값 공유
  ..name = 'las'
  ..xp = 1200000
  ..team = 'blue'
  ..sayHello();
```

- 프로퍼티 수정뿐 아니라 **메서드 호출**(`..sayHello()`)도 이어서 쓸 수 있다.
- `..`을 입력하면 자동완성에 `name`, `team`, `xp`, `sayHello()` 등이 나온다.

## 5. 강사의 코멘트

- 개발자를 위해 설계된, Dart를 좋아하게 만드는 편의 문법(syntax sugar)이다.
- Flutter에서 자주 쓰게 될 것이다.

## 정리

- `객체..프로퍼티 = 값..메서드()`처럼 **`..`** 으로 같은 객체에 여러 작업을 이어서 한다.
- 세미콜론은 **마지막에 한 번만** 붙인다.
- 새로 만든 객체와 이미 있는 객체 모두에 쓸 수 있다.
