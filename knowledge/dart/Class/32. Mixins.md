**생성자가 없는 클래스**의 프로퍼티와 메서드를 다른 클래스에 **가져다 쓰는** Mixin을 다루는 강의다. Flutter와 Flutter 플러그인에서 `with` 키워드를 자주 보게 된다.

## 1. Mixin이란

- [[31. Inheritance]]의 `Human`은 생성자가 있어서, 상속할 때 항상 `super`로 생성자를 호출해야 했다.
- Mixin은 **생성자가 없는 클래스**다.
- 다른 클래스에 **프로퍼티와 메서드를 추가**하는 용도로 쓴다.

## 2. Mixin으로 쓸 클래스 만들기

```dart
class Strong {
  final double strengthLevel = 1500.99;
}

class QuickRunner {
  void runQuick() {
    print("ruuuuuuuun!");
  }
}

class Tall {
  final double height = 1.99;
}
```

모두 생성자가 없다.

## 3. `with`로 가져오기

```dart
enum Team { blue, red }

class Player with Strong, QuickRunner, Tall {
  final Team team;

  Player({required this.team});
}

void main() {
  var player = Player(team: Team.red);
  player.height;         // Tall에서
  player.strengthLevel;  // Strong에서
  player.runQuick();     // QuickRunner에서
}
```

- `extends`가 아니라 **`with`** 를 쓴다.
- 여러 클래스를 쉼표로 이어서 한꺼번에 가져올 수 있다.
- `player.`을 입력하면 `height`, `strengthLevel`, `runQuick()`이 자동완성에 나온다.

## 4. 핵심은 재사용

Mixin을 한 클래스에서만 쓴다면 의미가 없다. **여러 클래스에서 재사용**할 수 있다는 점이 핵심이다.

```dart
class Horse with Strong, QuickRunner {}

class Kid with QuickRunner {}
```

## 5. `extends` vs `with`

|         | `extends` (상속)          | `with` (mixin)      |
| ------- | ----------------------- | ------------------- |
| 관계      | 상속한 클래스가 **부모 클래스**가 된다 | 부모 클래스가 되지 않는다      |
| `super` | 쓸 수 있다                  | 해당 없음               |
| 인스턴스    | 부모 클래스의 인스턴스가 된다        | 프로퍼티와 메서드만 **가져온다** |

강사는 mixin을 "그냥 가져다 쓰는(훔쳐 오는) 것"이라고 표현한다.

## 6. mixin이 되는 조건

강의에서는 **"생성자가 없는 클래스라면 mixin이다"** 라고 설명한다.

> [!warning] Dart 3부터 달라진 점
> 강의는 Dart 2.18(Flutter 3.3.6) 기준이다. **Dart 3.0부터는** 일반 `class`를 `with`로 섞을 수 없다. mixin으로 쓰려면 `class` 대신 **`mixin`** 키워드로 선언하거나, 클래스로도 쓰고 싶다면 **`mixin class`** 로 선언해야 한다.
>
> ```dart
> mixin Strong {
>   final double strengthLevel = 1500.99;
> }
>
> mixin class QuickRunner {  // 클래스로도, mixin으로도 사용 가능
>   void runQuick() {
>     print("ruuuuuuuun!");
>   }
> }
> ```
>
> 출처: [Dart 문서 - Mixins](https://dart.dev/language/mixins), [Class modifiers](https://dart.dev/language/class-modifiers)

## 정리

- Mixin은 **생성자가 없는** 클래스이고, `with`로 다른 클래스에 프로퍼티와 메서드를 추가한다.
- 여러 클래스에서 **재사용**할 수 있다는 점이 핵심이다.
- `extends`와 달리 부모 클래스가 되지 않는다.
- Dart 3부터는 `mixin` 또는 `mixin class`로 선언해야 한다.

※ 강의 화면의 프로퍼티 이름은 `strenghtLevel`(오타)이지만, 노트에서는 `strengthLevel`로 적었다.
