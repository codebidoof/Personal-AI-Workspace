기본 생성자 외에 **이름이 있는 생성자(named constructor)** 를 추가로 만드는 방법을 다루는 강의다. Flutter의 튜토리얼과 문서 어디에서나 볼 수 있는 패턴이다.

> [!note] 용어 구분
> - **named constructor parameters** ([[25. Named Constructor Parameters]]): 생성자의 **파라미터**를 이름으로 전달하는 것
> - **named constructor** (이번 강의): **생성자 자체**에 이름을 붙여 여러 개 만드는 것

## 0. 팁: 같은 타입 프로퍼티를 한 줄로 선언

```dart
class Player {
  final String name;
  int xp, age;   // int xp; int age; 와 같다
  String team;
}
```

같은 타입의 프로퍼티는 쉼표로 이어서 한 줄에 선언할 수 있다. 단, `final String name, team;`처럼 쓰면 `team`도 `final`이 되므로 주의한다.

## 1. 목표: 미리 설정된 Player를 만드는 생성자

기본 생성자 `Player(...)`는 모든 값을 받는다. 여기에 더해 다음 생성자들을 만들고 싶다.

- `Player.createBluePlayer`: `team`은 `'blue'`, `xp`는 `0`으로 고정하고 **name과 age만** 받는다.
- `Player.createRedPlayer`: `team`은 `'red'`, `xp`는 `0`으로 고정하고 **name과 age만** 받는다.

## 2. named constructor 만들기: `클래스명.이름(...) : 초기화`

```dart
class Player {
  final String name;
  int xp, age;
  String team;

  Player({
    required this.name,
    required this.xp,
    required this.team,
    required this.age,
  });

  Player.createBluePlayer({
    required String name,
    required int age,
  })  : this.age = age,
        this.name = name,
        this.team = 'blue',
        this.xp = 0;

  Player.createRedPlayer(String name, int age)
      : this.age = age,
        this.name = name,
        this.team = 'red',
        this.xp = 0;
}
```

- `Player.createBluePlayer`처럼 **`클래스명.생성자이름`** 으로 선언한다.
- 기본 생성자와 **다른 파라미터**를 받을 수 있다.
- 파라미터 뒤의 **콜론(`:`)** 이 Dart만의 특별한 문법이다. 콜론 뒤에서 **Player 객체의 프로퍼티를 초기화**한다.
  - 사용자에게 받은 값: `this.age = age`, `this.name = name`
  - 고정값: `this.team = 'blue'`, `this.xp = 0`
- 여러 개를 초기화할 때는 쉼표로 구분하고, 마지막에 세미콜론을 붙인다.

> [!note] 보충
> 콜론 뒤의 이 부분을 Dart에서는 **initializer list**(초기화 리스트)라고 부른다.

## 3. 사용하기

```dart
void main() {
  var player = Player.createBluePlayer(
    name: "nico",
    age: 21,
  );
  var redPlayer = Player.createRedPlayer("nico", 21);
}
```

- `createBluePlayer`는 **named parameters**를 쓰므로 `name:`, `age:`로 전달한다.
- `createRedPlayer`는 **positional parameters**를 쓰므로 순서대로 전달한다. named constructor라고 해서 꼭 named parameters를 써야 하는 것은 아니다.

### positional vs named 파라미터 복습

| | 기본 동작 |
|---|---|
| positional | **기본적으로 필수**. 빠뜨리면 에러 |
| named | **기본적으로 선택**. 필수로 만들려면 `required`를 명시 |

## 4. 강사의 코멘트

- 처음 보면 낯설고 익숙해지기 어려운 문법이다. 클래스 인스턴스를 직접 만드는 코드가 보이지 않지만, 편의 문법(syntax sugar)일 뿐이다.
- 하지만 Flutter에서 **아주 많이** 쓰게 되니 익숙해져야 한다.

## 정리

- named constructor는 **`클래스명.이름(...)`** 으로 선언해서, 기본 생성자 외에 여러 생성자를 만든다.
- 파라미터 뒤 **`:`** 다음에 프로퍼티를 초기화한다. 받은 값과 고정값을 섞어서 쓸 수 있다.
- named constructor의 파라미터도 positional과 named 중 원하는 방식으로 쓸 수 있다.
