다른 클래스가 구현해야 할 메서드를 정해 두는 **추상 클래스(abstract class)** 와 **추상 메서드**를 다루는 강의다.

## 1. 추상 클래스란

- 추상 클래스로는 **객체를 절대 만들지 않는다.** (`Human()`처럼 인스턴스를 만들 수 없다.)
- 다른 클래스들이 **직접 구현해야 할 메서드의 청사진(blueprint)** 역할을 한다.

## 2. 추상 클래스 만들기

```dart
abstract class Human {
  void walk();
}
```

- `abstract class 이름`으로 선언한다.
- 메서드는 **구현하지 않는다.** `print('walk')` 같은 본문 없이 **시그니처만** 적는다.
  - 시그니처: 메서드 이름, 반환 타입, 파라미터
- 위 코드는 "`Human`을 따르는 클래스는 `void`를 반환하는 `walk` 메서드를 가져야 한다"는 뜻이다.

## 3. 추상 클래스를 상속하기: `extends`

```dart
class Player extends Human {
  // walk()를 구현하지 않으면 에러가 난다
}
```

`Human`을 `extends`하는 순간, `Human`에 있는 `walk`를 `Player`가 구현하지 않았으므로 Dart가 에러를 낸다.

```dart
class Player extends Human {
  String name;
  // ...

  void walk() {
    print('im walking');
  }
}
```

`walk`를 구현하면 에러가 사라진다. 구현 방법은 원하는 대로 정하면 된다.

## 4. 여러 클래스가 같은 추상 클래스를 따르기

```dart
class Coach extends Human {
  void walk() {
    print('the coach is walking');
  }
}
```

- `Player`와 `Coach` 모두 `Human`을 상속하므로, **둘 다 `walk`를 가진다는 것이 보장**된다.
- 하지만 **걷는 방식(구현)은 각자 다르게** 정할 수 있다.

## 5. 강사의 코멘트

- Flutter에서 추상 클래스를 직접 쓸 일은 **많지 않다.**
- 어렵지도, 아주 중요하지도 않지만 알아 두면 유용하다.

## 정리

- `abstract class`는 인스턴스를 만들 수 없고, **구현해야 할 메서드의 시그니처**만 정해 둔다.
- 추상 클래스를 `extends`한 클래스는 그 메서드를 **반드시 구현**해야 한다.
- 여러 클래스가 같은 메서드를 갖는다는 것을 보장하면서, 구현은 각자 다르게 할 수 있다.
