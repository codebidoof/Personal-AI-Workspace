Classes 섹션의 첫 강의다. 강의에서는 이 섹션을 **코스의 메인 요리**라고 부른다. Flutter에서는 모든 것이 클래스이고, 직접 만드는 컴포넌트도 클래스이기 때문이다. 클래스 문법에 익숙해지고, TS/JS, Java, C# 등과 무엇이 다른지 알아야 한다.

## 1. 클래스 정의하기

```dart
class Player {
  String name = 'nico';
  int xp = 1500;
}
```

- 클래스의 **프로퍼티는 타입을 명시**해서 선언한다.
- 함수 안의 지역 변수는 `var`를 쓰지만, 클래스 프로퍼티는 타입을 적는다. ([[4. The Var Keyword]]의 컨벤션)

## 2. 인스턴스 만들기

```dart
void main() {
  var player = Player();
  print(player.name); // nico
  player.name = 'las';
  print(player.name); // las
}
```

- 클래스 이름을 함수처럼 호출하면 인스턴스가 만들어진다. `new` 키워드는 필요 없다.
- `player.`을 입력하면 자동완성에 `name`, `xp`가 나온다. 값을 읽을 수도, 바꿀 수도 있다.

## 3. `final` 프로퍼티

[[7. Final Variables|변수에서 배운 수식어]]를 클래스 프로퍼티에도 똑같이 쓸 수 있다.

```dart
class Player {
  final String name = 'nico';
  int xp = 1500;
}

player.name = 'las'; // ❌ final 프로퍼티는 수정할 수 없다
```

## 4. 메서드와 `this`

```dart
class Player {
  final String name = 'nico';
  int xp = 1500;

  void sayHello() {
    print("Hi my name is $name");
  }
}

void main() {
  var player = Player();
  player.sayHello(); // Hi my name is nico
}
```

- 메서드 안에서 프로퍼티를 쓸 때 **`this`를 쓰지 않아도 된다.** `$name`은 `${this.name}`과 같다.
- `this.name`도 동작하지만, Dart에서는 **`this`를 생략하는 것이 권장**된다.

### `this`가 필요한 경우: shadowing

(아래 예시 코드는 강의 설명을 바탕으로 직접 작성한 것이다.)

메서드 안에 프로퍼티와 **같은 이름의 변수**가 있으면, 그냥 `name`은 그 지역 변수를 가리킨다. 이때 프로퍼티를 가리키려면 `this.name`을 써야 한다.

```dart
void sayHello() {
  var name = '121';
  print("Hi my name is ${this.name}"); // 프로퍼티 name (nico)
}
```

## 5. 아직 남은 문제

지금은 모든 Player가 **같은 name과 xp**를 가진다. 인스턴스를 만들 때 값을 넘길 수 있게 하려면 **생성자(constructor)** 가 필요하다.

## 정리

- `class 이름 { 타입 프로퍼티 = 값; }`으로 클래스를 정의한다. 프로퍼티는 타입을 명시한다.
- `var player = Player();`로 인스턴스를 만든다.
- 프로퍼티에 `final`을 붙이면 수정할 수 없다.
- 메서드 안에서는 `this` 없이 프로퍼티를 쓴다. 같은 이름의 지역 변수가 있을 때만 `this`를 쓴다.
