Hello World 코드를 통해 Dart 프로그램의 **`main` 함수**와 **세미콜론 규칙**을 다루는 강의다.

```dart
void main() {
  print('hello world');
}
```

## 1. `main` 함수: 모든 Dart 프로그램의 진입점

`main` 함수는 **모든 Dart 프로그램의 진입점(entry point)** 이다. Dart는 실행할 때 자동으로 `main`을 찾아 호출한다. 많은 프로그래밍 언어가 같은 방식을 쓴다.

함수 이름을 `main`이 아닌 다른 이름(예: `hello`)으로 바꾸면 실행되지 않는다.

- **VS Code**: `main` 위에 있던 `Run` 버튼이 사라진다. `dart run main.dart`로 실행하면 다음 에러가 난다.
  ```
  Dart_LoadScriptFromKernel: The binary program does not contain 'main'.
  ```
- **DartPad**: 실행하면 다음 에러가 난다.
  ```
  Error: No 'main' method found.
  Error: Compilation failed.
  ```

### 코드는 어디에 작성하는가

- 클래스나 타입 정의 같은 것은 `main` **바깥**에 작성한다.
- 실제로 **무언가를 실행하는 코드는 모두 `main` 안**에 작성한다. Dart가 호출하는 것은 `main`이기 때문이다.

## 2. 세미콜론은 반드시 직접 붙여야 한다

`print` 함수는 Python처럼 간단하지만, Dart에서는 **문장 끝에 세미콜론(`;`)이 반드시 필요하다.** 빠뜨리면 컴파일되지 않는다.

- DartPad에서는 `error line 2 • Expected to find ';'.` 에러가 표시된다.
- JavaScript나 TypeScript에서는 포매터(예: Prettier)가 저장할 때 세미콜론을 자동으로 붙여 준다.
- **Dart에서는 저장해도, `Format`을 눌러도 포매터가 세미콜론을 추가하지 않는다.** VS Code와 DartPad 모두 마찬가지다.

### 자동으로 붙여 주지 않는 이유

Dart에는 **일부러 세미콜론을 쓰지 않아야 하는 문법**이 있기 때문이다. 강의에서는 **Cascade 연산자(`..`)** 가 그 예라고 언급하고, 자세한 내용은 뒤에서 다룬다.
JS/TS에서 넘어왔다면 세미콜론을 생략하는 습관이 있을 수 있으니 특히 주의한다.

## 3. 다음 강의 예고

다음 강의에서는 Dart의 변수를 다룬다. `var`, `const`는 다른 언어에서도 익숙하지만 `final`, `late`는 새로운 개념이고, Null Safety도 함께 다룬다.

## 정리

- `main`은 모든 Dart 프로그램의 **진입점**이다. 이름이 반드시 `main`이어야 하고, 실행할 코드는 `main` 안에 작성한다.
- 문장 끝의 **세미콜론은 필수**이고, 포매터가 자동으로 붙여 주지 않는다. Cascade 연산자 같은 문법 때문이다.
