한 번 값을 정하면 **다시 바꿀 수 없는 변수**를 만드는 `final` 키워드를 다루는 강의다.

## 1. `var`와 명시적 타입 변수는 수정할 수 있다

[[4. The Var Keyword]]에서 본 두 방식은 모두 **나중에 값을 바꿀 수 있는** 변수를 만든다. 단, 같은 타입으로만 바꿀 수 있다.

```dart
var name = 'nico';
String name2 = 'nico';

name = 'las'; // ✅
name = 12;    // ❌ int는 String에 넣을 수 없다
```

하지만 대부분의 경우에는 변수가 바뀌지 **않기를** 원한다.

## 2. `final`: 한 번만 할당할 수 있는 변수

`var` 자리에 `final`을 쓰면 된다.

```dart
final name = 'nico';
name = 'las'; // ❌ 컴파일 에러
```

> The final variable 'name' can only be set once.
> — `assignment_to_final_local`

강의에서는 JavaScript/TypeScript의 **`const`에 해당한다**고 설명한다.

> [!note] 보충
> Dart에도 `const` 키워드가 따로 있고, `final`과 의미가 다르다. `const`는 **컴파일 시점에 값이 정해져야 하는** 상수다. 자세한 내용은 [[9. Constant Variables]]에서 다룬다.

## 3. 타입을 함께 적을 수도 있다

```dart
final String name = 'nico'; // 가능하지만 필수는 아니다
final name = 'nico';        // 컴파일러가 String으로 추론한다
```

타입을 적어도 되지만 필요하지 않다. 컴파일러가 타입을 잘 추론하므로 **`final name = ...`처럼 짧게 쓰는 편이 낫다**고 강의에서 권한다.

## 정리

- `var`나 명시적 타입으로 만든 변수는 **수정할 수 있다.**
- **`final`** 로 만든 변수는 **한 번만 할당**할 수 있다. JS/TS의 `const`와 비슷하다.
- `final String name`처럼 타입을 적을 수 있지만, 보통은 생략하고 추론에 맡긴다.
